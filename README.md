# horennsoBOT

こちらは1～2年ほど前に連絡関係でトラブルがあり、改善のために   
①スマホでもPCでも使いやすい  
②discordのみで完結する  
③手軽  
な連絡用BOTを目指して作成しました。  

ただこちら実装段階前に都合でご破算になったため、動作確認はしておりません。  
また、あくまで独学かつ、数人で使用するために作成したものであり、セキュリティ等の問題は考慮しておりません。  
加えて、一部コード作成や修正等にAIを使用しております。  

基本的な機能は  
①連絡事項のジャンル分け  
②連絡事項と相談者を特定のチャンネルに送信  
③相談者とのチャットにボタン一つで返信  
の予定でした。  

こだわった部分は  
「面倒だから後回し」が起きにくいボタン、プルダウン形式  
名前が変わっても相談者がひとめでわかるよう、IDで認識
